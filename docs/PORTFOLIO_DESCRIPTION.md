## 100-word portfolio description

Indenture operationalizes the private-credit deal workflow end to end. Inbound opportunities are qualified against lender mandates with deterministic checks, evaluated for qualitative fit by an LLM that must explain its reasoning, and routed to a human reviewer who approves or overrides with a recorded rationale. Company enrichment fills information gaps and re-runs eligibility; decided deals hand off to CRM with visible status. Pipeline Intelligence surfaces real operational metrics, and a prioritized "Needs Attention First" queue explains exactly what needs a decision-maker's time first — every claim backed by recorded data, never estimated. Built with Next.js, FastAPI, Supabase and Groq.

## Resume project entry

**Indenture — AI-powered Deal Intelligence & Operations Platform**
*Next.js · TypeScript · FastAPI · Supabase · Groq (LLM) · HubSpot/Apollo adapters* | [indenture-snowy.vercel.app](https://indenture-snowy.vercel.app)

- Built an end-to-end deal-operations workflow for private-credit origination: mandate qualification, AI-assisted evaluation with written evidence, human approval/override with mandatory rationale, and CRM handoff with a complete audit trail.
- Designed a two-layer decision system — deterministic mandate checks plus validated LLM qualitative fit — that keeps hard criteria consistent while surfacing information gaps and recommended next actions for reviewers.
- Implemented operational analytics and pipeline health: bottleneck detection (stale reviews, pending and failed CRM handoffs, missing-information holds) and a severity-ranked, explained follow-up queue computed from recorded data only.
- Architected environment-gated integration adapters (HubSpot CRM, Apollo enrichment) with honestly labeled demo fallbacks, so the full workflow runs — and discloses itself — with or without third-party credentials.

---

## Three key capabilities demonstrated

1. **Business workflow design** — translating a messy, real operational process (intake → qualification → review → handoff) into a structured product with clear accountability at the human decision point.
2. **Operational analytics from first principles** — surfacing bottlenecks and prioritizing follow-ups using only data the system records, with an explanation attached to every surfaced item.
3. **Pragmatic AI integration** — using an LLM as an evidence-producing recommendation engine inside a deterministic rules framework, with honest, environment-gated integration boundaries rather than simulated success presented as real.

## LinkedIn short explanation

Most deal pipelines break at the seams: untracked decisions, invisible information gaps, handoffs nobody owns. I built **Indenture** to fix that — an AI-powered deal intelligence and operations platform for private-credit origination. It qualifies inbound opportunities against lender mandates, produces AI recommendations with written evidence, puts a human signature on every decision, routes outcomes to CRM, and shows operators exactly what needs attention first — with the reason on every line.
